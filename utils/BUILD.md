# Сборка Windows EXE

Откройте `utils/build_pyinstaller.py` в PyCharm и нажмите Run. Выберите рабочий
интерпретатор проекта с установленными PyInstaller и зависимостями программ.
Рабочая директория в Run Configuration может быть любой.

В консоли введите номера через пробел или запятую, например `01 04 08`.
`all` собирает все десять программ, пустой ввод завершает работу.
Для постоянного выбора без меню задайте в начале скрипта
`SELECTED_PROGRAMS = ["01", "04"]`.
Альтернатива — поле Parameters в PyCharm: `01 04`.
Добавьте `--dry-run`, чтобы только проверить пути и команды без изменений.

| Номер | Программа | Папки внутри dist |
|---|---|---|
| 00 | hiSDloader | VA_PC_CV/cams_media |
| 01 | hiFTPDloader | VA_PC_CV/cams_media, VA_PC_client/cams_media |
| 02 | hiFTPCleaner | VA_PC_CV/cams_media |
| 03 | CVloadAntifreeze | VA_PC_CV/cams_media, VA_PC_client/cams_media |
| 04 | CVdbViewer | VA_PC_CV, VA_PC_client |
| 05 | CVsetCam | VA_PC_CV |
| 06 | MissingPhotoFinder | VA_PC_CV |
| 07 | SysViscountEval | VA_PC_CV |
| 08 | CVdbUpdater | VA_PC_client |
| 09 | hiSampler | VA_PC_CV |

Дополнительно каждая выбранная программа размещается в корне `dist`
с тем же полным именем и суффиксом версии.

Папки назначения и исходные списки исключений находятся в
`utils/pyinstaller_programs.json`. Выбирается исходник с наибольшим числом
после `_v` в корне проекта. Имя EXE полностью повторяет имя выбранного исходника,
включая числовой префикс и версию: например, `01_hiFTPDloader_v4.exe`,
`08_CVdbUpdater_v3.exe` и `09_hiSampler_v3.exe`. В конфигурации задаются только
папки: при повышении версии исходника менять конфигурацию не нужно.

Сборка идет в `temp/pyinstaller/<номер>/output`. Только после успешной сборки
удаляются прежние EXE этой программы в целевых папках: с версией или без нее,
включая старые числовые префиксы. Это правило действует и в корне `dist`.
Посторонние файлы и дистрибутивы других программ не затрагиваются.
Перед заменой создаются резервные копии. При ошибке копирования/удаления выполняется
восстановление, а резервные копии остаются в указанной в ошибке папке.
Перед сборкой закройте заменяемые программы. При ошибке обработка очереди прекращается;
уже успешно обновленные программы остаются обновленными.
