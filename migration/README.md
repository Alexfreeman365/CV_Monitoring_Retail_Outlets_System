# Миграция CSV в SQLite

Инструменты однократного перехода вынесены из корня проекта.
Полная инструкция: `../archive/Видео-аналитика_руководство_по_миграции_v2.docx`.

## Запуск

Из корня новой системы, используя её подготовленную среду:

```powershell
.\.venv\Scripts\python.exe .\migration\migrate_csv_to_sqlite.py 'D:\VA_transition'
```

Аргумент — папка, содержащая `db` с исходными CSV/Excel. Используйте отдельную
копию без рабочей SQLite-базы. Если аргумент пропущен, используется текущая
рабочая папка. Скрипт импортирует `utils.db` из родительского проекта.

Скрипт не копирует фотографии и не запускает нейросеть. Он пропускает отсутствующие
файлы и пишет наборы поэтапно, без общей транзакции. Повторный запуск заменяет
данные ряда таблиц. После ошибки сохраните журнал, исправьте копию источников
и повторите перенос в новую чистую папку; затем проверьте весь результат.

Прогноз читается из `visitor_forecast_actual.csv`, а новая система экспортирует
`visitor_forecast.csv`. Перед переносом проверьте имя и схему файла.

`export_visitors_csv.py` остаётся в корне: это ручной экспорт из действующей
SQLite-базы для Excel, а не инструмент миграции. Ядро выполняет тот же экспорт
автоматически после расчёта дня.
