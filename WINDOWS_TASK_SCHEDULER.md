# Запуск CV pipeline через Windows 11 Task Scheduler

## Как это работает

Задача запускает `run_cv_task.ps1` в видимом PowerShell-окне. Скрипт использует
проектную `.venv`, задаёт корень проекта как рабочий каталог и запускает
`CV_SYS_v2.py` без буферизации вывода.

В окне остаётся исходный компактный вывод `CV_SYS_v2.py`, без дополнительных
сообщений о проходах по камерам. После того как по штатному выводу видно, что все
магазины обработаны, нажмите в этом же окне **Ctrl+C один раз**. Это штатный
сигнал остановки для Python. После него `CV_SYS_v2.py` запускает подсчёт
посетителей и контроль продавцов для закрытых магазинов, сохраняет служебную
информацию и делает backup базы.

Когда исходный вывод финальных алгоритмов закончится, launcher покажет приглашение
`Pipeline stopped. Press Enter to close the terminal`. Окно не исчезнет само,
поэтому результат можно проверить и затем нажать `Enter`.

> Не используйте **End / Завершить задачу** в Task Scheduler и не закрывайте окно
> крестиком для штатной остановки: это может завершить Python без финальных
> алгоритмов и backup.

## Создание ежедневной задачи

Откройте обычный PowerShell от своего пользователя (права администратора не
нужны), перейдите в корень проекта и задайте время запуска, например 21:30:

```powershell
Set-Location 'D:\pjs\CV_Monitoring_Retail_Outlets_System'
powershell.exe -NoProfile -ExecutionPolicy Bypass `
    -File .\install_cv_scheduled_task.ps1 -DailyAt '21:30'
```

Время должно быть в 24-часовом формате `HH:mm`. Установщик намеренно не
перезаписывает уже существующую задачу с тем же именем.

## Первый тест

Запустить созданную задачу вручную:

```powershell
Start-ScheduledTask -TaskName 'CV Monitoring - Main Pipeline'
```

Должно появиться отдельное окно PowerShell. Дождитесь полного обхода камер,
нажмите `Ctrl+C`, дождитесь завершения исходного вывода финальных алгоритмов и
нажмите `Enter`.

Если окно не появляется, в свойствах задачи проверьте параметр **Run only when
user is logged on / Выполнять только для вошедшего пользователя**. В режиме
«Выполнять независимо от регистрации пользователя» Windows запускает задачу в
неинтерактивной сессии, где видимый терминал невозможен.

## Удаление задачи

```powershell
Unregister-ScheduledTask -TaskName 'CV Monitoring - Main Pipeline'
```
